# ATAC-seq historical pilot evidence

This directory preserves compact evidence of the development and validation
history of the ATAC-seq workflow before cleanup of large historical outputs.

The canonical scientific result is SLURM job 10318071.

Earlier jobs are retained here only as technical or methodological history:

- 10280253: paired-end filtering technical validation using a multiome run.
  This dataset is not biologically eligible for the bulk CHO atlas.
- 10297369: bulk CHO alignment/filtering/TSS pilot.
- 10300242: verification of existing ATAC outputs.
- 10302460: peak calling and FRiP pilot.
- 10304910: IDR/reproducibility pilot.
- 10308134: validated BigWig pilot.
- 10318071: canonical end-to-end production validation.

Historical pilot metrics must not replace production metrics in the TFM.

Large pilot outputs may be removed only after explicit cleanup authorization.
The Git repository and this evidence capsule preserve the methodological record.
